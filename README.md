# Trip Planner

A mobile-first, interactive travel planning web app.

## Pages
- **Plan** (`index.html`) – the trip at a glance: hero header with countdown, day-by-day timeline, interactive map, budget summary.
- **Edit** (`edit.html`) – add/reorder days and activities, set places, times, costs and notes.

## Stack
Plain HTML, CSS and JavaScript (no build step). Leaflet + OpenStreetMap for maps.
Data is stored in the browser (localStorage) with JSON import/export.
Hosted free on GitHub Pages.
