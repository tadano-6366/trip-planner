# Food board — fill-in template

How to fill in:
- One block per food option. **Copy a block to add one, delete a block to remove one.**
- Leave anything you don't know blank.
- **Stall / address**: the stall or shop name plus street works best (e.g. "Siam Road Char Koay Teow, Jalan Siam").
  Claude looks up the map location for you.
- **Price**: `$` cheap · `$$` mid · `$$$` treat
- **Hours**: e.g. `10:00-18:00` or `6pm-2am` (late-night is fine)
- **Closed on**: e.g. `Tue` or `Mon, Thu`
- Photos you already added stay as they are.

When done: paste this into the chat with Claude, or edit this file on GitHub and tell Claude.
